# Why this file exists

# PROJECT_BLUEPRINT.md §4 already splits the project in two:
#   * TRAINING  — Chronos fine-tune, Darts ensemble, LSTM-AE, XGBoost — runs on

# PyCaret enforces that split at the dependency level: every pycaret 3.3.x
# release pins pandas<2.2.0, which cannot co-exist with the pandas>=2.2 /
# numpy 2.x that darts, tensorflow and prophet resolve to in requirements.txt.
# Attempting both in one environment gives pip ResolutionImpossible.
#
# Colab gets its own throwaway environment per session, so the older pandas
# here costs nothing. PyCaret remains part of the delivered stack for the RFP
# tool list — it just runs on the training side of the line.
